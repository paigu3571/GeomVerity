# 产品AI重放数据

本目录保存公开样例的产品问答、规则起草、术语分类和通知请求/响应，以及合成引用校验控制。它们是产品功能的实验与Trace证据。

| 数据 | 使用方 |
|---|---|
| 根目录问答与两个draft缓存 | cst.demo、问答/草案重放和测试 |
| naming中的七个缓存 | 112种房名候选实验的重放 |
| notifications中的稳定引用缓存 | 两版提资通知的离线重放 |
| SYNTHETIC_validator.json | 人工构造的错误引用控制 |

保留实际提示词、工具请求、回复和校验状态，才能追查模型参与的范围。缓存不包含请求认证头或API key；输入为公开脱敏样例。源数据、提示词或配置变化时，应生成新缓存，不修改旧记录冒充同一次调用。

私人模型讨论、未脱敏请求和未使用的开发试验不在此目录新增。产品模型提示词保留在Python模块中，属于功能实现。

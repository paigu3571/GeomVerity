# v0.4.0-beta.1（预览版）

> 预览版。维护者于2026-10-28明确授权“可以发布”。程序ZIP及SHA-256沿用已核对候选；最终实拍、视频、原生退出及完整人工验收仍按下方清单保留，不因发布升级为通过。

GeomVerity把工程AI意见、图纸对象和人工复核依据放在一起，当前以CAD换版复核为验证场景。

## 这一版能做什么

- 在本机打开公开示例或已有扫描JSON，查看资料缺口和图面来源。
- 按房间看两版变化，区分原确认仍可用、需要对应确认或因变化失效。
- 对照工程意见与图纸记录，不一致项可跳到对应人工复核。
- 记录当前房间、当前事项的意见和待补资料；驳回后回待处理，履历保留。
- 导出可核对文件摘要的证据包，保留原文、依据和本机人工记录。

## 下载与启动

附件：`GeomVerity-v0.4.0-beta.1-windows-x64.zip`、`SHA256SUMS.txt`。ZIP大小92,434,048字节。

ZIP SHA-256：`c6a980deb239e4e3051c270f25243ecede493f00e7c605e8396fe94db887d8b3`

下载后解压整个文件夹，双击`GeomVerity/GeomVerity.exe`。需要Windows与Microsoft Edge WebView2 Runtime。不要拆开EXE与配套文件；可加`--browser`使用本机浏览器。先选公开A→A-change，B是另一张图。

## 已知局限

工作台不直接读DWG，自己的图纸需要先在合法CAD宿主采集。现有宿主实测范围为AutoCAD 2016 + 天正T20 V8。规则仅覆盖有限机房场景，缺净长、有效出口、上层资料或隔墙做法时无法判定。AI文字核验不覆盖全部自然语言；普通文件摘要和自报姓名不等于身份认证、数字签名或设计批准。灯具、照度仍是实验候选，不能直接施工。

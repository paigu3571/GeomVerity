## 维护者试用清单（尚未完成）

1. 解压完整ZIP，双击EXE；确认首页三份公开示例和资料缺口提示，B不作为A的新版。
2. 比较A→A-change，先看预留充电桩配电房删门及原确认失效，再看商业配电房来源对应。点看图定位，再返回；核对缺资料说明和关联房间是否清楚。
3. 载入公开工程意见，核对AI不一致项跳转是否对应当前房间/事项；不把两项不一致当作只检测到两处图纸改动。
4. 在一项复核中写自己的意见并保存；在已记录中找到它，驳回后确认返回待处理且历史仍可查看。登记资料未齐后应进入待补资料，自动工具结论保持不变。
5. 查看图面灯具候选、深浅文字和定位；切换到人工记录后返回图面，体验加载与视图保留。实验灯具不能当设计已通过。
6. 选择导出目录，导出并重开证据包，检查房间、意见、原文和文件校验；最好在另一台Windows电脑再完成启动、复核和导出。
7. 记录等待时间、失败步骤和截图；补齐本版四张实拍与演示视频。维护者完整45分钟试用前不因探针通过而跳过人工关口。

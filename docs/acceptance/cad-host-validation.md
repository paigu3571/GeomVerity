# CAD宿主验证

历史手动验证使用AutoCAD 2016/T20 V8和0.3.0-dev插件。A/B对应的原扫描统计为：

| 项目 | A来源 | B来源 |
|---|---:|---:|
| Space | 73 | 48 |
| 电气用房宽类 | 14 | 21 |
| Shaft | 12 | 8 |
| Opening | 638 | 279 |
| Opening—Space关系 | 524 | 170 |
| 完整对象引用链 | 5799 | 2522 |

这些数量与既有0.2.11扫描一致，不代表全部识别正确。公开A/B是脱敏旧快照，不能冒称由本次构建重新扫描。

复现步骤见[构建与加载](../guides/cad-build.md)。保存图纸后JZBPSCAN，运行`python -m cst summary "<扫描结果目录>"`；需要检查源字节时运行`python -m cst verify "<扫描结果目录>" --dwg "<源DWG>"`。

本次治理不改C#扫描源码；构建和核心测试在治理报告中单列。没有执行新的CAD加载/扫描时，不能将编译通过当宿主验证通过。

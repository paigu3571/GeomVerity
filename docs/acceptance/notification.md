# 协作通知验收

运行 `python -m cst.demo --changes-only`，打开 `dist/demo/notifications/notice.html`。开头显示优先/复核/记录数量，正文三组有独立标题。每句话显示模板或模型来源和校验状态，时间来自版本登记，采用北京时间。

光厅和充电桩电表间的派生围合差异进入“仅记录”，显示程序识别波动，不通知建筑专业修改。采光井本阶段暂缓区域语义，不新增设计语义。真实源门窗改动即使房间轮廓没变，也可通过模板列入关联房间复核。房名重复时按面积、WCS位置与文字来源区分。

`notice.json`保留原模型回答、引用校验与独立presentation；正式通知只采用经程序分组后的presentation。模型缓存不因页面改版而重调。消息未自动发送，供工程师签字后复制。

# 演示图像

图像来自公开A到A-change数据生成的真实离线查看器，后台无界面Chrome截图。notice.jpg为真实缓存重放通知正文的阅读排版。

viewer-default、door-risk、water-risk、lamp-evidence、notice为五个审阅画面。recognition-before/recognition展示切换前后；demo.gif由五个真实截图顺序播放，单次10秒，不是实时速度录像。

GIF使用Pillow生成，工具说明：https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html 。图像不包含原DWG或私人CAD窗口。

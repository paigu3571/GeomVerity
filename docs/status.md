# 能力状态（v0.4.0-beta.1 预览版）

定位：工程 AI 成果可追溯与多层核验。CAD 换版复核是当前验证场景。实现、离线验证与专业人工验收分别记录。

| 能力 | 实现范围 | 验证边界 |
|---|---|---|
| 本机工作台 | 项目/体检、图面、换版、AI核验、人工复核、导出 | 发布分支本轮检查见[验收](acceptance/release-0.4.md)；异机与完整专业验收待补 |
| CAD采集 | CAD宿主导出L1/L2/L3 JSON，按已有配置识别 | 已有宿主范围为AutoCAD 2016 + T20 V8，不代表其他版本全面兼容 |
| 换版 | 同图比较、来源配对、限定电气影响候选 | 不能把零候选当全图无影响；匹配歧义保留待复核 |
| 旧确认 | inheritance.2，原范围继承/需对应确认/失效 | 只沿用原条件，不是整房或整图签字 |
| AI文字 | claims-check.4，引用、面积、有限状态；完整原文和划分履历 | 无验证器为未知；不证明全部自然语言或识别正确 |
| 人工复核 | engineer-reviews.v1，本机意见与待办/补资料/驳回履历 | 自报姓名，非身份认证/数字签章；工具结论独立保留 |
| 证据包 | 文件清单、摘要、源引用与人工记录导出/重开校验 | 完整性不等于工程正确、可信时间戳或签名 |
| 布灯与照度 | 规则生成候选、墙段与开口约束、估算输出 | 实验中；局部间距和工程参数仍须人工确认，不能施工 |
| MCP | 只读对象、变化、影响及主张核验 | 无人工记录写入或工单同步接口 |
| 客户定制/自动生图 | 扩展点与分层方向 | 计划中；新采集器、专业规则、L4/L5受控生成须另行实施验收 |

公开例的8项人工修改清单是事后对照，不是AI检出数或准确率统计。当前测试通过也不代表真实盲标、原生完整点击、跨机器或专业审查通过。

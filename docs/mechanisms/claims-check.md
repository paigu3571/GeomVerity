# 一条AI主张怎样得到核验结果

**输入是什么**：保留的完整原文、句子位置、明确引用的对象/决策编号，以及原文声称的结构化数值或状态。原文生成方与划分方分开记录。只判断划出的内容，未划内容不在覆盖范围。

**怎么判断**：引用查找只问“这项记录在所给资料中是否存在”；面积分别读原记录和按几何重算；确认状态读对应决策并核查继承策略。面积每种观测各用 `max(0.01 m², 观测面积×0.005)`，避免把浮点或微小轮廓差异直接当错。0.01 m²是绝对下限，0.5%随面积变大；它们是可配置核验参数，不是规范允许误差。

**输出什么**：“支持”是已声明字段与所用资料相符；“矛盾”是有可用依据反驳该字段；“未知”是缺数据、无验证器或无法可靠计算；“需复核”包括读取与重算分歧、旧依据已变，或来源待确认。两种面积方法一支持一反驳，要交人工，不由程序随意挑一个。执行是否成功、使用何种方法、人工复核和报告是否仍适用另列，不能揉成一个“通过”。

**什么情况交给工程师**：对象识别或轮廓有疑问、面积方法不一致、来源不能唯一对应、复杂专业结论或原确认范围不明。冻结模式只问“AI有没有如实描述当时的资料”；当前重核可以指出旧说法已经过时，两者不能混用。

**不做什么**：不验证任意自然语言，不把引用存在当整句都正确，不把未知当错误或当通过，也不为结果好看改原文、放宽容差或代替人签字。

# 换版后旧确认为什么不能直接照搬

**输入是什么**：同一图纸的旧、新两版扫描；旧确认人、确认范围；确认依赖的房间、门洞候选、规则版本及原始来源。旧确认可能只说“这些输入条件已核对”，不等于整间房设计签字。

**怎么判断**：先确认旧、新对象是否能唯一对应，再分别核对内容、来源身份、候选集合和规则。都未变且原确认材料可用，才把原条件真正带入新版重算，记为“继承”。内容未变但句柄或来源实例变化，记为“待来源确认”，不会自动继承，也不会直接判失效。内容、规则或候选集合变化，或匹配不足，记为“失效”。没有原签字单列“无原确认”。

**输出什么**：同一个核心判断同时产生决策继承、房间输入复核和新版检查记录。没有实际带入确认，就不能显示已继承。确认人、原范围、输入指纹和理由保留，来源确认也绑定两版资料；资料再变，不能继续套用这次确认。

**什么情况交给工程师**：商业配电房只换来源的情形，需原确认人核对旧、新来源及门洞对应后明确确认。预留充电桩配电房确有几何和门洞变化，应重新核查输入。操作后重算，以实际检查结果为准，确认按钮本身不是“通过”。

**不做什么**：不把近邻匹配当身份保证，不扩大原确认范围，不自动签字，不因某条输入确认就宣称整间房或整图合规。

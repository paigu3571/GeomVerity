# 证据包能证明到哪一步

**输入是什么**：扫描与比较记录、规则依据、逐条主张报告、完整原文、编辑履历和已有人工复核记录。导出前重新检查它们是否对应当前上下文，避免拿修改前的旧报告交接。

**怎么判断**：把收录文件及其哈希列进清单。重开时先核对文件与清单，再核对报告与扫描、比较及人工上下文的对应关系。篡改、遗漏或不匹配会阻止展示核验结果。原包和原报告保留，不静默覆盖为“新结果”。

**输出什么**：可交接的只读包、HTML/CSV清单及完整性检查结果。收件人能查当时用了什么资料、哪句话查了什么字段、哪些输入由谁在什么范围确认。实验候选和专业结论应区分阅读。

**什么情况交给工程师**：确认文件是否属于这次工程、复核人是否有权、所填范围是否足够，以及原DWG和专业资料是否齐全。包中可能只有原图的路径/哈希，并不保证附带DWG、全部YAML或外部资料，缺件需要另行取得。

**不做什么**：文件一致不证明识别或设计正确；普通哈希清单不是数字签名、身份认证或第三方时间戳。有人同时重写文件和清单时，单靠自带哈希不能证明原作者。只读重开不是恢复可编辑工程，也不替代授权、签署或专业验收。

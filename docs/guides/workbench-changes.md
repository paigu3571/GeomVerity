# 换版与复核

先读[工作台上手](workbench.md)。A→A-change为公开同图换版，B为另一张图，不能混比。比较记录使用changes.v2，旧确认采用inheritance.2。

按房间查看源变化、工程影响候选和旧确认，三者数量不同。没有找到对应房间可能是围合/标注识别问题，不能直接认定拆除。来源编号变化也不能单凭编号判定实物改动。详情保留源引用与技术字段，工程师先看房间、变化、需补资料和下一步。

对于旧确认，内容和规则未变但来源身份更新时，需要人工核对对应关系再沿用。输入或依赖变化时原确认失效；从未有人确认的记录单列，不能称旧签字失效。所有沿用只限原有条件。

人工记录与专业规则分开。保存不会把无法判定改为通过；驳回后回待处理并保留履历。记录范围默认当前房间，不能据此替整房或整图批准。

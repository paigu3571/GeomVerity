# 工作台上手

## 图纸从哪里来

公开示例 A 与 A-change 是同一图纸的两个版本，B 为另一张图。自己的资料须先由 CAD 采集器导出快照 JSON；当前宿主实测范围为 AutoCAD 2016 + 天正 T20 V8，其他宿主不能据此声称兼容。采集器构建见 [CAD 构建](cad-build.md)，换图注意事项见[适配说明](drawing-adaptation.md)。工作台首页提供采集说明及 CAD 定位命令；没有通用的一键启动 CAD、自动跨宿主扫描功能。

## 一次复核

1. 首页先体检扫描状态、单位、房间和资料缺口。零房间、扫描失败或缺失文件不能解释为没有问题。
2. “换版”选择同图旧、新版，在按房间清单选房间。源变化条数、影响记录条数和人工改动次数是不同口径。
3. 看改了什么、可能影响什么、需要补什么。点“看图核对”，对照轮廓、门洞及关联房间；复制 CAD 命令可回对应源图定位。
4. AI核验加载公开意见或输入自己的意见。核对只覆盖已划分主张及支持的验证器；完整原文保留。点“不一致”进入对应人工事项；没有规则覆盖的对象只能查看源变化。
5. “人工复核”只记录当前房间当前事项。填写姓名、意见与房间范围；范围不是整间房设计签字。缺少净长、实际出口数、上一层资料或隔墙做法时，按提示向相应专业补资料。
6. 已记录项可在“已记录”与完整本地履历查看。“资料未齐”进入待补资料；驳回后返回待处理，旧记录保留。工具结果不会因写意见自动变成通过。
7. 导出所选内容与证据包，重开先校验清单。保存和沿用可能需要重新核对规则，当前仍有等待。

当前“房间复核”是有限建筑空间/电气机房场景。可扩展规则和采集器，但新增客户场景、专业和宿主均需单独实施与验收，不属于现成通用能力。

## 人工记录的意义

记录将房间、事项、意见、复核人自报姓名、时间、上下文指纹与处理状态关联起来，方便下一版判断原意见是否仍适用。导出包的 engineer-reviews.json 可由后续系统按约定读取；目前没有工单双向同步、Agent写入审批或 L4/L5 自动生图授权接口。它不是身份认证或电子签章，未来应用还需权限、审批与实际工程验收。

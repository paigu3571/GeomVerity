# 给工程师的标注说明（一页）

A是C01，B是C03。用Excel打开eval中的A_gold.csv、B_gold.csv；每行是一处系统认为的空间。原图在本地资料目录，图纸不上传仓库。

1. 先在原图找到该房间，核对房名、范围和大致面积。对象编号、系统用途、几何面积和状态不要改。
2. 在“人工用途”填写你认为真实的用途。不能确定写“待确认”，不要为了与系统一致而迁就。
3. 在“是否真实空间”填“是/否/待确认”。像“面积”这种标注、房间上空等不能直接算成实际房间，按图纸判断。
4. 已识别行的“是否漏检”通常填“否”。图上确有房间但表中完全没有的，填到A_missed.csv或B_missed.csv：自编序号、房名、真实用途、图中位置和漏掉的原因。原因可选未闭合、名称图层、词典缺失、其他、不确定；看不出原因就填不确定。
5. 备注可写轮廓不对、多个房间合并、名称误配等。面积空白表示系统没有可用面积，不是零；面积有值也只用于核对，不替代设计计算。
6. 标注范围应覆盖所选区域；若只核对一块区域，请在备注注明范围，区域外不要猜漏检数量。

保存时尽量使用“CSV UTF-8（逗号分隔）”。当前只是待填写模板，没有准确率结果；用途词表不替代对房间范围的人工标注。

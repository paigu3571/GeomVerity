# 已知局限

## CAD与数据

插件实测宿主为AutoCAD 2016＋T20 V8；其他组合未验证。默认配置包含具体图层和制图约定，换标准需核对映射、围合与术语。Python读取配套JSON，可独立于CAD运行。[适配与缺口处理](drawing-adaptation.md)。曲线、圆和含bulge的路径经过采样后，现有IsExact标记仍可能高估精确性；影响范围包括几何状态、面积和相关派生字段，未给出宿主量测误差评估。

空间围合和房名位置可能不一致。Python补提取保持源图引用，但输出是候选；不能替代工程师对真实房间范围的确认。原生墙未变时，派生轮廓仍可能产生微小差异，须与建筑修改分开报告。

## 规则与换版

Opening关系是门洞候选，不能直接等同有效出口。隔墙关系、用水或热源用途及专业措施需要相应证据。单层R3缺少上一层语义，返回无法判定。有限区域内未发现影响候选，不表示整套电气设计无影响。

Handle可能因对象分解或跨图处理重编号；近邻匹配也可能存在歧义。记录源变化、派生变化与识别缺口，不把程序候选条数当人工修改次数。只有依赖和规则保持相容的原确认才可继承。

## AI与布置

引用校验覆盖对象、显式数值和部分状态表述，不证明所有自然语言正确。术语与规则需要专业批准。缓存必须对应输入、提示词和配置；SYNTHETIC结果不能当真实图纸评测。

灯具是几何布置候选。有效闭合房间可按演示参数回算LPD与利用系数法平均照度估算，异形房间使用RI=2A/(h·P)。h=2.4m、U=0.7等有明确演示来源；规范表格值、光分布及驱动损耗尚未完整核实，不输出正式照明合规结论。

桌面工作台已完成窗口和核心调用探针，完整人工交互验收仍未完成。模型或桌面不可用时，确定性读取、规则和证据处理可单独运行。

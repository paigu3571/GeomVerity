# 路线图

下表为维护计划，具体交付随数据、评测和贡献进展调整。

|时间|计划|
|---|---|
|2026Q4|稳定0.3版与追溯契约，推进多楼层、多楼栋分析，扩充公开样例；每月一个小版本|
|2027Q1|完善跨楼层输入，推进电气规则与机电图元，维护规则版本与术语审批|
|2027Q2|完善机电图元与评测，探索电气点位随建筑变化调整，并推进给排水、暖通、BIM接入|
|2027Q3|扩展建筑、结构、内装、景观、幕墙、人防等专业协作与社区规则贡献|
|2027Q4|依据评测完善SDK/MCP与年度复现，探索机械、电路等CAD相关领域|

pywebview仅保留实验代码，不属于0.3参赛主交付；后续按需要完成整套交互验收。主交付保持CAD插件、Python核心和离线Viewer。

## 图纸与宿主适配（计划）

2026Q4先整理默认配置边界、社区图层对照及小范围人工答案，积累逐项验证记录；2027上半年推进自动盘点、缺口提示与兼容性矩阵，按贡献情况验证其他宿主组合。优先复用配置与验证数据，不要求穷举所有设计院标准。[贡献方式](../guides/drawing-adaptation.md)。

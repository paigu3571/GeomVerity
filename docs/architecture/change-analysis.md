# 版本匹配与影响分析

输入为同一坐标系的旧、新JSON快照。变化包括新增、删除、几何、名称/用途、来源对象及输入状态；输出双方源Handle和匹配方法。保存/扫描时间属于版本记录，不是逐对象编辑时刻。

## 匹配级联

实现位于python/cst/changes.py。先匹配唯一房名文字证据及实例上下文，再比较同类对象的WCS几何；几何容差为0.001mm。随后处理同类源Handle/实例/外参上下文，剩余房间使用同名和真实轮廓IoU≥0.5辅助匹配。

派生对象Handle可能重编号或被复用，不能一律当作永久身份。重复几何和容差多重候选有identity_unverified标记；不据此继承确认。同名房间的IoU候选近似时不强制配对。匹配参数是实现选项，不是规范阈值。

## 影响与旧确认

对象位于已识别电气房间内或近邻时产生影响候选；隔墙贴邻和规则结果补充专业风险。范围内没有候选时输出“限定范围内未发现影响候选”。缺几何或用途时保留资料缺口。

只有相关房间、门洞候选及规则依赖相容，旧确认才可继承。任一依赖变化则失效；以前未确认的条目不补造签字。灯组和已执行计算随相关几何变动重新评估。

优先级由后端生成，Viewer只呈现。改动清单、失效确认和待重做工作见[变更验收](../acceptance/changes.md)。

# 本机工作台结构

Python desktop.py 提供仅绑定回环地址的会话服务，Windows WebView2壳与浏览器共用 workbench.html。页面按项目、图面、换版、工程意见、人工复核、导出分工，静态资源打包在 cst/assets，不依赖远程CDN。

ui_assets.py 装配CSS、脚本与图标；颜色使用tokens。Python核心负责规则与核验，前端只组织显示和明确操作。图面按相同输入复用iframe及视图状态；扫描、规则、比较或人工上下文变化时，后端撤下过期结果并重核。

回环地址不是跨网络服务；接口按会话令牌、Host/Origin约束保护。本机自报复核不等于身份认证。MCP只读，与工作台写入意见分离。

原生窗口、浏览器检查和工程师人工验收是不同层面。构建资源验证用于核对包内字节，不替代实际交互。
